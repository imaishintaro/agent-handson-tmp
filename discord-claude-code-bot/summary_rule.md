# 会話要約ルール

このファイルの指示に従って会話履歴を要約してください。

## 出力フォーマット

```
## 概要
（全体のトピックを1〜2文で）

## 主なトピック・決定事項
- （箇条書き）

## 覚えておくべきこと
- ユーザーの好み・設定・習慣など、次回以降に役立つ情報
- 決まったこと・合意したこと

## 未解決・継続中
- （あれば記載、なければ省略）
```

## 要約のルール

- 日本語で書く
- 簡潔に、でも重要な情報は落とさない
- ユーザー名や固有名詞はそのまま残す
- コードや技術的な内容は要点だけ残す
- 雑談・挨拶は省略してよい
- 「ユーザー」「アシスタント」ではなく内容で判断する
