## おすすめ観戦スポット

**御堂筋**
- 5km地点から難波まで約3km続く直線コース
- 道幅が広くて観戦しやすい
- 地下鉄御堂筋線でアクセス良好

**道頓堀周辺**
- THE大阪って感じの名所
- 難波駅からすぐ（御堂筋線・千日前線・四ツ橋線）
- 盛り上がりがすごそう

**大阪城公園**
- フィニッシュ地点だから感動的
- 森ノ宮駅から近い

## 時間と交通規制
- **時間**: 7:15頃〜16:35頃まで広範囲で交通規制
- 御堂筋、千日前通、天神橋筋など主要道路が通行止めになるから、電車でのアクセスがおすすめ

応援naviっていうアプリでランナーの位置も追えるから、知り合いが走ってるなら使ってみて！
