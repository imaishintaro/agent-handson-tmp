# パックマンゲーム

Pygameを使用したシンプルなパックマンクローンです。

## 機能

- 🎮 矢印キーでパックマンを操作
- 👻 ゴースト（敵）との追いかけっこ
- ⚪ ドットを全部食べてクリア
- 🏆 スコアシステム

## 操作

| キー | 動作 |
|------|------|
| ↑ | 上に移動 |
| ↓ | 下に移動 |
| ← | 左に移動 |
| → | 右に移動 |
| R | ゲームオーバー/勝利後にリスタート |

## インストール

```bash
pip install -r requirements.txt
```

## 実行

### Mac/Linux
```bash
./run.sh
```

### Windows
```batch
run.bat
```

または直接Pythonで実行:
```bash
cd src
python main.py
```

## ゲームルール

1. 迷路内の全てのドット（白い丸）を食べるとクリア
2. パワードット（大きな白い丸）は50ポイント
3. 通常ドットは10ポイント
4. ゴーストに触れるとゲームオーバー
5. 全てのドットを食べると「YOU WIN!」
