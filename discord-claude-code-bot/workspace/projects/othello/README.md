# オセロゲーム

コマンドライン上で遊べるオセロ（リバーシ）ゲームです。

## 必要な環境

- Python 3.8以上

## セットアップ

1. 依存パッケージのインストール（現在は標準ライブラリのみ使用）
```bash
# 特に追加パッケージは不要
```

2. 実行
```bash
# Linux/Mac
./run.sh

# Windows
run.bat

# または直接Pythonで実行
python src/main.py
```

## ゲームの遊び方

1. ゲーム開始時は黒（●）が先手
2. 座標を「行 列」形式で入力（例: 3 4）
3. 相手の石を挟むように置く
4. 置ける場所がない場合はパス
5. 両方がパスするかボードが埋まったらゲーム終了

## ボード表記

- ● : 黒石
- ○ : 白石
- . : 空きマス
- * : 置ける場所（ヒント表示時）
