# ブロック崩し（Breakout）ゲーム

Pythonとpygameで作られたクラシックなブロック崩しゲーム。

## 特徴

- **リアルタイム物理演算**: 精密な衝突判定と反射
- **多様な操作方法**: キーボード（矢印キー/WASD）、マウス操作
- **本格的なゲーム性**: 耐久度システム、スコア、残機、無限ステージ
- **視覚効果**: ボールのトレイルエフェクト、カラフルなブロック
- **オブジェクト指向設計**: クラスを責務ごとに分離した保守しやすい構造

## 必要な環境

- Python 3.8以上
- pygame 2.5.0以上

## セットアップ・実行

### 1. 依存関係のインストール

```bash
pip install pygame>=2.5.0
```

### 2. ゲーム実行

```bash
# スクリプトで実行（推奨）
./run.sh            # Linux/Mac
run.bat             # Windows

# または直接実行
python3 src/main.py
```

## 操作方法

| キー | 操作 |
|------|------|
| **← →** または **A D** | パドルの左右移動 |
| **マウス移動** | パドルをマウスに追従 |
| **SPACE** | ボール発射 / ゲーム開始 |
| **P** | ポーズ / 再開 |
| **ESC** | 終了 |

## ゲームルール

1. **目標**: パドルでボールを跳ね返してすべてのブロックを破壊
2. **スコア**: ブロックの行によって異なる得点（上の行ほど高得点）
3. **耐久度**: 上2行のブロックは2回ヒットで破壊
4. **残機**: 初期3機、ボールを下に落とすと減少
5. **ステージ**: 全ブロック破壊でクリア、レベルアップして継続

## 技術的特徴

### アーキテクチャ

```
src/
├── main.py           # エントリーポイント
├── class_game.py     # ゲーム状態管理
├── class_paddle.py   # パドルクラス
├── class_ball.py     # ボール物理演算
├── class_brick.py    # ブロック管理
├── class_block.py    # ブロッククラスのエイリアス
└── func_utils.py     # 定数・ユーティリティ
```

### 主要クラス

- **Game**: ゲームループ、状態機械（タイトル→プレイ→ゲームオーバー）
- **Paddle**: プレイヤー操作、反射角度計算
- **Ball**: 物理演算、トレイルエフェクト、衝突判定
- **BrickGrid**: ブロック群の管理、衝突検出

### 物理演算

- **精密衝突判定**: 円（ボール）と矩形（ブロック・パドル）の正確な衝突
- **反射角度変化**: パドルの端で打つと急角度で反射
- **速度制御**: ブロック破壊に応じた速度増加
