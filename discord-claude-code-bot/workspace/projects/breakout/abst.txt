# ブロック崩しゲーム（Breakout）

## 概要
Pygameを使用したクラシックなブロック崩しゲーム。
パドルでボールを跳ね返しながら、すべてのブロックを破壊することが目標。

## 主な機能
- リアルタイム物理演算（ボール・パドル・ブロックの衝突判定）
- 6段階のカラフルなブロック配置（上段ほど高得点）
- パドル位置による反射角度調整システム
- ライフ制（3回ミスでゲームオーバー）
- スコアシステムとハイスコア記録
- ゲーム状態管理（タイトル・プレイ中・ポーズ・ゲームオーバー・クリア）
- 滑らかなアニメーション（60FPS）

## ゲームの遊び方
- 左右矢印キー：パドル移動
- スペースキー：ゲーム開始・ポーズ切り替え
- Rキー：リスタート（ゲームオーバー・クリア後）
- ESCキー：ゲーム終了

## 技術要素
- Python 3.8+
- Pygame 2.5.0+
- オブジェクト指向設計（5つのクラスによるモジュール分割）
- 状態機械パターンによるゲーム管理
- リアルタイム衝突判定アルゴリズム
