# Brainf*ck テトリスプロジェクト

極限までミニマルなプログラミング言語Brainf*ckでテトリスを作るプロジェクト。

## 現在の進捗
- [x] Hello World (基本動作確認)
- [ ] 数値出力
- [ ] 入力処理
- [ ] 画面描画システム
- [ ] ブロック表現
- [ ] テトリス本体

## ファイル構成
- `hello.bf` - コメント付きHello World
- `hello_compact.bf` - コンパクト版Hello World

## Brainf*ck基本コマンド
- `>` : ポインタを右に移動
- `<` : ポインタを左に移動
- `+` : セルの値を1増やす
- `-` : セルの値を1減らす
- `.` : セルの値を文字として出力
- `,` : 1文字入力してセルに保存
- `[` : セルが0なら対応する]へジャンプ
- `]` : セルが0以外なら対応する[へジャンプ

## 実行方法

### オンラインインタープリター
1. https://copy.sh/brainfuck/ にアクセス
2. .bfファイルの内容をコピー&ペースト
3. 「Run」をクリック

### ローカル実行
```bash
# インタープリターをインストール
# macOS (Homebrew)
brew install bf

# Ubuntu/Debian
sudo apt install bf

# 実行
bf hello.bf
```
