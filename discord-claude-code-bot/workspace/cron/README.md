# Cron スケジューラー

`crontab.json` を編集することで、AIへの定期指示を設定できます。
ファイルを保存するとボットが自動で再読み込みします（再起動不要）。

---

## crontab.json の設定項目

| フィールド    | 説明                                      | 例                          |
|-------------|-------------------------------------------|-----------------------------|
| `id`        | ジョブのユニークなID                        | `"daily-report"`            |
| `description` | ジョブの説明（Discordに表示される）        | `"毎日の日報"`               |
| `cron`      | cron式（Asia/Tokyo基準）                   | `"0 9 * * *"`               |
| `channelId` | 送信先DiscordチャンネルID                   | `"1234567890123456789"`     |
| `prompt`    | AIへの指示プロンプト                        | `"今日の作業をまとめて"`      |
| `enabled`   | `true` で有効、`false` で無効              | `true`                      |

---

## cron式の書き方

```
┌─────── 分 (0-59)
│ ┌───── 時 (0-23)
│ │ ┌─── 日 (1-31)
│ │ │ ┌─ 月 (1-12)
│ │ │ │ └ 曜日 (0-6, 0=日曜)
│ │ │ │   │
* * * * *
```

### よく使うパターン

| cron式          | タイミング           |
|----------------|---------------------|
| `0 9 * * *`    | 毎日 9:00           |
| `0 9 * * 1-5`  | 平日 9:00           |
| `0 18 * * 1-5` | 平日 18:00          |
| `0 9 * * 1`    | 毎週月曜 9:00        |
| `0 0 1 * *`    | 毎月1日 0:00        |
| `*/30 * * * *` | 30分ごと            |
| `0 9,18 * * *` | 毎日 9:00 と 18:00  |

---

## チャンネルIDの確認方法

1. Discordの設定 → 詳細設定 → 開発者モード をON
2. 対象チャンネルを右クリック → 「IDをコピー」

---

## スラッシュコマンド

| コマンド          | 説明                              |
|-----------------|-----------------------------------|
| `/cron-list`    | 登録済みジョブの一覧を表示           |
| `/cron-reload`  | crontab.json を手動で再読み込み     |
