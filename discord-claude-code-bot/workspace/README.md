# Workspace フォルダ構成

クロウ（AI秘書）との作業用ワークスペースです。

## フォルダ構成

```
workspace/
├── 📁 projects/          # 開発プロジェクト（プロジェクト名ごと）
├── 📁 daily/             # 日常利用（メモ・スクリプト・チャットログ）
├── 📁 memory/            # 記憶・コンテキスト管理
├── 📁 assets/            # メディアファイル（画像・PDF等）
├── 📁 tmp/               # 一時フォルダ（sandbox・inbox）
├── 📁 tools/             # AIが使うツール保管
└── 📁 shared/            # 共有ユーティリティ・ドキュメント
```

## 使い方
1. 新しいプロジェクトは `projects/` 内に作成
2. 日常的なメモは `daily/notes/` に保存
3. 実験・お試しは `tmp/sandbox/` で作業
4. 重要な情報は `memory/` で管理

## 管理ルール
- tmpフォルダは定期的に整理する
- 重要なファイルは適切なフォルダに移動する
- プロジェクト完了後は整理・アーカイブする
